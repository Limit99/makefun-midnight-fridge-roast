# A Judgmental Stare

A tiny Node/TypeScript program for the make.fun bounty "Midnight Fridge Roast". It writes one funny single-line roast to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 200 characters.

Entry line:

> At 3 a.m. my fridge hums like it works overtime, but the only thing it ever produces is a light and a judgmental stare at my leftovers.

Run it with: `node main.ts`
